# v14 — extended reach and dynamic crosshair

Confirmed working by the user on Meta Quest 2 PC VR, October 28, 2026.

Changes since v12:

- Crosshair display reaches 50 metres instead of 5, matching the existing targeting trace.
- Apparent crosshair size decreases gradually with distance, with a minimum size for readability.
- Aiming at GAL, MiniKurona, or MiniRisu enemies shrinks the crosshair another 20%.
- Size transitions smoothly and recovers when aiming away.
- Preserves the right-hand Ekoro gun, barrel alignment, menu navigation, trigger selection, and menu sizing.

Download `GalGun2_VR_Ekoro_Gun_v14.zip`. Close the game, back up the previous mod pair outside `Paks`, and extract both `EkoroPrototype_P.pak` and `EkoroPrototype_P.sig` directly into `GalGun2/Content/Paks/~mods`. Replace the previous mod pair; remove any differently named older versions. Do not replace original game archives.

The ZIP includes installation/removal instructions and SHA-256 checksums. These are the exact binaries tested by the user, without additional gameplay changes. The internal build identifier retains its original `test` suffix; the binary hashes identify the confirmed build.

Tested game: Windows Steam build 3345483. Other builds/headsets are unverified. Two-handed grip is not included. Menu diagnostic crosshair colors are retained.
